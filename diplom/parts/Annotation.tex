\begin{center}
\textbf{Эффективные методы сканирования OCI-образов по метаданным}

\textit{Зиганшин Марк Радикович}
\end{center}

\vspace{0.7cm}

\begin{center}

В данной работе рассматривается задача повышения эффективности сканирования OCI-образов на наличие известных уязвимостей. Произведен обзор предметной области, изучены устройство OCI-образов, особенности их хранения в container registry, а также основные принципы, на которых базируется работа современных сканеров уязвимостей. Рассмотрены ключевые сканеры с открытым исходным кодом~--- Trivy, Clair, Grype~--- и выявлен общий для них недостаток: при сканировании из registry слои образа скачиваются целиком, тогда как для анализа в большинстве случаев требуется лишь небольшая часть содержимого, представленная метаданными пакетных менеджеров и манифестами зависимостей. В качестве пути решения предложено использование формата eStargz, поддерживающего пофайловую загрузку содержимого слоёв из registry. Разработан форк сканера Trivy, реализующий ленивую загрузку файлов через TOC eStargz-слоёв. Также разработан фреймворк для воспроизводимого бенчмарка, моделирующий типичный профиль нагрузки на container registry. По результатам экспериментальной оценки разработанный прототип демонстрирует кратное ускорение сканирования и существенное снижение объёма скачиваемых из registry данных по сравнению с обычным Trivy, при этом сопоставимый по скорости с альтернативными сканерами.

\end{center}
